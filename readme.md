# 宝宝识字（Early Literacy）

面向 5 岁左右小朋友的**离线识字练习**应用：屏幕上显示一组田字格汉字，孩子根据语音提示点选正确的字。答对有星星与语音夸奖，答错会高亮正确字并安排重练；后台按遗忘曲线自动安排复习。

纯前端实现，数据保存在浏览器 localStorage，**双击 `index.html` 即可使用**，不需要安装、启动服务或联网。

---

## 1. 快速开始

1. 双击项目根目录的 `index.html`（`file://` 方式直接打开）。
2. 首页点「+ 创建小朋友」，输入名字。
3. 点小朋友名字 → 选择册（如「一年级上册」）→ 开始练习。
4. 家长可点首页左下角的 ⚙ 进入后台，管理小朋友、设置每题候选字数和每组题数。

> 建议使用 Chrome / Edge 最新版；界面按平板与桌面横屏设计，也适配手机竖屏。

## 2. 功能一览

### 练习流程
- **多小朋友**：每个小朋友有独立的进度与历史记录，首页点头像即可切换。
- **按册学习**：按 `tools/data/volume-*.txt` 拆分字库，选册页显示「共 N 字 · 已学 · 待复习」。
- **4 / 6 / 8 选 1**：后台可配置每题候选字数；6 个时 3 列、8 个时 4 列，卡片自动缩小且始终居中。
- **每组 5 ~ 20 题**：后台可配置题数，结束页星星数随之最多 20 颗。
- **首答计分**：只有第一次作答计星、计正确率；答错的题会排到本组队尾再练一次，重练不再计分。
- **答错讲解**：答错后正确卡片绿色脉冲高亮，需家长点「继续」才进入下一题。
- **跳过 / 结束**：跳过不计对错、不得星；练习页顶部的「结束」会二次确认，已作答记录保留，并回到该小朋友的册目选择页。
- **结束页**：逐颗弹出星星、正确率、本组新学会的字，并语音播报星数；可点「继续答题」在同一册直接开始下一组，或「返回」回到册目选择页。

### 辅助开关（状态会记住）
- **拼音**：显示/隐藏卡片顶部的拼音。
- **组词**：显示/隐藏底部组词提示（隐藏后语音仍会朗读组词）。
- **🔊 / 🔇**：朗读与音效总开关。
- **历史记录里的「汉字」**：控制历史记录中汉字与图例的显隐。

### 记忆与记录
- **遗忘曲线**：答对升级（10 分钟 → 1 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天），答错归零并 10 分钟后重现。
- **出题优先级**：到期复习字 → 新字 → 已学未到期字（错得越多越容易被抽中）。
- **历史记录**：从选册页进入，显示最近 50 组的时间、星星、本组答对/答错的汉字；可一键清除当前小朋友的全部进度与历史。

### 其他
- 全部资源本地化，离线可用。
- 禁用鼠标右键菜单，避免小朋友误操作。
- 语音优先播放预生成的「晓晓」真人女声，缺文件时自动跳过或用系统语音兜底。

## 4. 字库维护

### 4.1 编辑字库

字库源文件为 `tools/data/volume-<册号>.txt`，UTF-8 编码，用 **Tab** 分隔三列，首行表头可保留：

```
汉字	拼音	组词
天	tiān	天空、白天
地	dì	大地、土地
```

- **拼音**使用带声调符号的形式（`tiān`、`nǚ`、`de`）；轻声可省略调号。
- **组词**用 `、` `，` `,` `/` `；` `;` 分隔多个词，语音会读成「天空的天，白天的天」。
  - 个别字放在句尾会被 TTS 误读（如「的还」读成 huán）。这类情况在 `tools/scripts/gen_words_audio.py` 的 `PRONOUNCE_ALIAS` 例外表中登记：按拼音映射到一个读音固定的同音字（如 `"hái": "孩"`），句尾改用该字，发音即锁定为正确读音；组词部分本身不受影响。以后遇到新的误读，往表里加一行，再用 `python tools/scripts/gen_words_audio.py <文件名>` 强制重生成对应音频即可。
- 多音字请写成多行（如「长 cháng」「长 zhǎng」），按「汉字|拼音」分别记录进度。
- 所有册之间的「汉字+拼音」只保留**首次出现**（按册号从小到大），后续册再出现不会重复加入；同一册内重复同样去重，格式错误行会跳过并提示数量。

### 4.2 重新生成前端字库

修改 txt 后必须执行：

```bash
python tools/scripts/build_volumes.py
```

或双击 **`tools/生成字库.bat`**。成功后刷新页面即可（必要时强制刷新）。

### 4.3 册名

`tools/data/volume-titles.txt`：

```
volume-1=一年级上册
```

未配置的册显示为「第 N 册」。新增 `volume-2.txt` 后补一行、再运行生成字库即可。

## 5. 语音生成（可选）

语音全部离线预生成，运行时不需要联网或调用云端 TTS。

### 5.1 环境准备

```bash
pip install edge-tts
```

脚本使用 `zh-CN-XiaoxiaoNeural`（晓晓），语速 `-5%`。需要网络下载语音，生成完成后即可离线使用。

### 5.2 生成脚本

以下批处理都位于 `tools/` 目录，双击运行即可（脚本会自动切到项目根目录）：

| 脚本 / 批处理 | 作用 | 输出 |
|---|---|---|
| `生成字库.bat` | 字库 txt → JS | `data/volumes.js` |
| `生成通用提示语.bat` | 生成“请找出/答对啦/完成啦”等通用提示 | `assets/audio/phrases/*.mp3` |
| `生成音节语音.bat` | 按拼音生成单字发音（同音字共享，自动避开常见多音字） | `assets/audio/syllables/<拼音键>.mp3` |
| `生成组词语音.bat` | 生成「X的X，X的X」整句 | `assets/audio/words/<字>_<拼音键>.mp3` |
| `生成名字语音.bat` | 按 `tools/data/names.txt` 生成名字专属语音 | `assets/audio/users/<名字>/*.mp3` |
| `生成星星语音.bat` | 生成「你得到了 N 颗星星！」 | `assets/audio/phrases/stars0~20.mp3` |
| `一键生成全部语音.bat` | 依次执行以上五个语音脚本 | 同上 |

所有脚本都可重复运行：**已存在且大小正常的文件会自动跳过**，新增字/名字时只需再跑一次。

音节音频会为每个拼音挑选一个发音代表字，并优先避开「还、长、乐、数」等常见多音字，避免单字朗读时选错读音（如 `hái` 改用「孩」）。如果仍有个别音节读音不对，可把该字加入 `tools/scripts/gen_syllable_audio.py` 的 `POLYPHONES`，删除对应 `<拼音键>.mp3` 后重跑。

重新生成音频后，浏览器可能仍播放旧文件：把 `index.html` 里的 `CACHE_VERSION`（当前 `27`）+1 即可，所有音频与清单都会自动换新地址。

### 5.3 命名规则

- 拼音键：去掉声调符号，声调数字后置；`ü` 写作 `v`；轻声记 `5`。
  - `kàn` → `kan4`　`nǚ` → `nv3`　`de`（轻声）→ `de5`
- 单字发音：`syllables/kan4.mp3`，同音字共用。
- 组词讲解：`words/我_wo3.mp3`。
- 名字语音：`users/刘看山/welcome.mp3`、`praise1~3.mp3`、`wrong.mp3`、`done.mp3`、`cheer.mp3`。

### 5.4 回退策略

- 单字发音缺失：整句交给系统语音朗读「请找出：X，……的X」。
- 组词音频缺失：只播单字。
- 通用提示语（`phrases/welcome|find|praise1~3|wrong|done|cheer.mp3`）缺失：该段自动跳过，不阻塞流程。
- 名字没有预生成语音：先用系统语音念名字，再播后续语音。

> 通用提示语（`phrases/welcome|find|praise1~3|wrong|done|cheer.mp3`）由 `生成通用提示语.bat` 生成；如仍缺失，该段会自动跳过，不影响答题流程。

## 6. 本地数据与配置

所有数据保存在当前浏览器的 localStorage（换浏览器/清缓存会丢失）：

| 键 | 说明 |
|---|---|
| `early-literacy-users` | 小朋友列表 `[{ id, name }]` |
| `early-literacy-current` | 当前小朋友 id |
| `early-literacy-progress:{id}` | 该小朋友的进度，以「汉字+拼音」为键，值为 `{ level, correct, wrong, lastReview, nextReview }` |
| `early-literacy-history:{id}` | 该小朋友的历史，最多 50 组 |
| `early-literacy-sound` | 朗读开关，`0` 为静音 |
| `early-literacy-pinyin` | 拼音显示，`0` 为隐藏 |
| `early-literacy-words` | 组词显示，`0` 为隐藏 |
| `early-literacy-showchars` | 历史记录汉字显示，`0` 为隐藏 |
| `early-literacy-quiz-options` | 每题候选字数：`4` / `6` / `8` |
| `early-literacy-quiz-count` | 每组题数：`5` ~ `20` |

旧版单用户数据（`early-literacy-progress` / `early-literacy-history`，以汉字为键）会在首次启动时自动迁移到默认小朋友「小朋友」。

## 7. 常见问题

**改了字库但页面没变化？**
先运行 `tools/生成字库.bat` 生成 `data/volumes.js`，再刷新页面。

**新增小朋友没有真人名字语音？**
把名字加入 `tools/data/names.txt`，运行 `tools/生成名字语音.bat`；未生成时会用系统语音念名字。

**某道题没有读音？**
运行 `tools/生成音节语音.bat` / `tools/生成组词语音.bat` 补齐；跑脚本后会自动刷新清单。

**改了 JS/CSS 但浏览器还用旧文件？**
项目使用统一缓存版本：修改任何 `css/js/音频/字体` 后，只需把 `index.html` 头部的 `CACHE_VERSION` +1，全部资源都会换上新的 `?v=`，无需逐个修改。

**手机和电脑田字格字体不一样？**
只有田字格里的汉字使用内置的 Windows 楷体（SimKai）子集 `assets/fonts/kaiti.woff2`（约 110KB），其余界面文字跟随系统字体。发布时**必须把 `assets/fonts/` 一起上传**；新增字库后运行 `tools/生成字库.bat`，它会先重建字库、再自动更新字体子集，最后把 `CACHE_VERSION` +1 即可。

**发布后第一次出题没有声音，点「再听一遍」才响？**
音频是首次播放时才联网下载的。现在进入册目页和开始练习时都会预下载本组音频（`Speaker.preload`），正常网络下不会再出现；如果仍然偶发，说明那几秒网络确实较慢，会等下载完成后自动播放。

**清空某个小朋友的记录？**
选册页 → 历史记录 → 「清除记录」（仅影响当前小朋友），或后台删除该小朋友（进度与历史一并删除）。

## 8. 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无构建、无依赖。
- 通过 `<script>` 引入字库与音频清单，避免 `file://` 下 `fetch` 被浏览器拦截。
- 语音：预生成 mp3 + `Audio` 队列播放（可打断）；发布环境会提前 fetch 成 blob 预下载，避免首次播放没声音；系统语音使用 Web Speech API 兜底。
- 字体：只有田字格汉字使用内置 Windows 楷体（SimKai）子集 `assets/fonts/kaiti.woff2`（约 110KB），界面文字用系统字体；新增字库后运行 `tools/生成字库.bat` 会自动重建子集。
- 音效：Web Audio API 实时合成，无需音频文件。
- 详细设计见 [design.md](design.md)。
